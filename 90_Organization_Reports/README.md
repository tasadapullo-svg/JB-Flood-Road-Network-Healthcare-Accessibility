# JB Flood Healthcare Accessibility Research Archive

This directory is an English-named, copy-and-verify organization of the original research files. The original source directories were not modified.

## Directory Structure

- `01_Historical_Flood_2016_2026/`: annual flood records, event evidence, flood locations, flood polygons, master datasets, and source archives.
- `02_GIS_Baseline_Data/`: administrative boundaries, road network data, elevation/DEM data, population data, healthcare facilities, rainfall, satellite imagery, spatial layers, and GIS projects.
- `03_Nature_Portfolio_Project/`: manuscript materials, section drafts, figures, tables, references, submission materials, and supporting information.
- `04_Figure_Support_Data/`: figure-specific support data, shared GIS assets, intermediate outputs, and final exports.
- `90_Organization_Reports/`: inventory, mapping, duplicate, archive, large-file, and QA reports.

## Integrity Controls

- Files were copied rather than moved from the original source folders.
- SHA-256 checksums were used for exact duplicate detection and copy verification.
- Only verified exact duplicates were excluded from the organized canonical copy.
- Duplicate original-file copies were copied to `_Duplicate_Quarantine_Not_For_Publication` outside this publication archive.
- Large files in `GitHub_Ready/` were split into binary parts no larger than 20 MiB and accompanied by restore metadata.
