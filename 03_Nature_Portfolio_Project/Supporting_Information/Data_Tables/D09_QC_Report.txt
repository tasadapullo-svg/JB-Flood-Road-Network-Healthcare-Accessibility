D09 — FLOOD SUSCEPTIBILITY / CRITICAL ROAD PRIORITY INDEX
Version: v1.0

1. PURPOSE
Combine the evidence-based flood susceptibility screening from D08 with
healthcare-network structural criticality from the corrected D06R routing model.

Two distinct products are intentionally kept separate:

A) NETWORK-WIDE PREPAREDNESS CRPI
   For all D01 core road segments.
   Answers: which flood-susceptible roads deserve proactive resilience / inspection / mitigation attention?

B) OBSERVED-2025 RECOVERY PRIORITY
   For the four D07-F/D08 observed road closures.
   Answers: during the reconstructed March-2025 event, which documented closure sections matter most
   for restoring healthcare accessibility?

This separation prevents a structural screening index from being misrepresented as an observed causal effect.

They are NOT flood probabilities.

4. CRPI
CRPI = 100 × flood evidence score × healthcare criticality percentile.

CRPI is a relative preparedness screening index.
It is NOT:
- annual flood probability;
- expected annual loss;
- return period;
- a direct prediction of newly unreachable population.

The CRPI has strong association with rerouting/delay consequence in this targeted validation,
but weak association with newly unreachable population.

This is scientifically important:
high baseline population dependency does not automatically mean that closing one segment creates isolation,
because network redundancy matters.

- CRPI is appropriate for PREPAREDNESS SCREENING;
- actual EVENT RECOVERY ORDER should use explicit D08 closure-removal consequences.

12. SCIENTIFIC TERMINOLOGY
Allowed:
- Critical Road Priority Index (CRPI)
- Flood susceptibility
- High-evidence susceptibility
- Potential susceptibility
- Healthcare-network criticality
- Recovery priority
- Preparedness priority

Not allowed without a later probability model:
- high flood probability
- 80% probability of flooding
- 1-in-N-year road failure probability
