# Data Availability

## Public Upstream Datasets

The study uses public or official upstream datasets including OpenStreetMap / Geofabrik road-network data, Copernicus GLO-30 terrain data, WorldPop population data, NASA GPM IMERG rainfall products, and official administrative or flood-related data sources where available. No new DOI is asserted here.

## Derived Data Included in This Repository

This repository includes selected derived products from D06R, D07, D08, D09, D10, and D11, including corrected baseline accessibility outputs, derived rainfall/event summaries, accessibility impact and sensitivity outputs, CRPI and critical-road products, recovery/equity products, and results-architecture support files.

## Large or External Files

Large raw source files are excluded from the Git repository to maintain repository size and reproducibility. Refer to [external_data/EXTERNAL_DATA_MANIFEST.csv](external_data/EXTERNAL_DATA_MANIFEST.csv).
