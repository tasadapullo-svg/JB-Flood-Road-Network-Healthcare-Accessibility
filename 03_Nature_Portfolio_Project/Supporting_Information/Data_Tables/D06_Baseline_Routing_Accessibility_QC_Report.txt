11. Routing-time interpretation
    Origin and hospital off-network snap distances are treated as map-matching offsets and are NOT added to road travel time.
    The baseline therefore represents road-network travel time between computational access points.

12. Shortest path output policy
    Dijkstra shortest paths are calculated on the directed network.
    To keep the reproducibility package tractable, 75,149 full path geometries are not materialized.
    Each origin stores its nearest hospital, minimum travel time, minimum directed network distance,
    threshold coverage, and hospital redundancy. The graph node/arc tables permit path reconstruction.

17. Method limitation
    Reference travel times depend partly on road-class fallback speeds where OSM maxspeed is absent.
    They must not be described as observed congestion travel times.
    Later flood scenarios should use this same baseline graph/speed model so that differences are caused by flood-network disruption rather than a changed baseline specification.
